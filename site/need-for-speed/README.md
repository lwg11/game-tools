# 极品飞车 · 霓虹海岸（Need for Speed 网页复刻）

参考主流程的网页版街机赛车：海滨城市赛道 + 4 种比赛模式 + 车辆养成经济 + 合成音效。
纯 Three.js + WebAudio，无构建步骤，部署后直接打开即玩。

线上 entry：`http://139.196.126.179:8092/games/need-for-speed/`

## 操作

| 输入 | 键位 |
| --- | --- |
| 油门 / 刹车 / 方向 | `W A S D` 或 `↑ ← ↓ →` |
| 手刹漂移 | `Space` |
| 氮气 | `Shift` |
| 静音 | `M` 或菜单右上角 🔊 |
| 触屏 | 虚拟油门/刹车/方向 + 漂移/氮气按钮（CDP 验过）；竖屏专用布局：速度表左上、小地图右上、触控按钮 68px、开始按钮吸底 |
| 金手指 | 选「疯狂模式」→ 菜单开关或游戏内「金」浮钮 |

## 模式

- **竞速**：3 圈 4 车，名次奖励 150/100/60/30 金币
- **漂移**：60 秒计分，>0 即胜，解锁「漂移者」涂装
- **淘汰圈**：每 20 秒末位淘汰，活到最后
- **警匪**：2 圈躲避警车拦截，耐久归零判负，胜解锁「执法者」涂装
- **自由漫游**：无目标全城开

AI 三档难度（业余/职业/车神，橡皮筋 ±12~18%）；模式/难度/金币 localStorage 持久化。

## 成长经济

- 车辆：mini/street 初始，muscle 500、exotic 1200
- 部件 5 系 × 5 级（100/180/300/450/650）：引擎(极速) 涡轮(氮气) 轮胎(抓地) 装甲(耐久) 氮气罐(容量)
- 涂装 8 款；车库 6 维性能条随升级实时变化（`buildDef` 统一补正）

## 技术要点

- 固定步长物理 1/60（CarSim：前向/侧向分解 + 指数抓地衰减 + 氮气）；渲染每帧，FOV/震屏/N 手
- Kenney Micro Poly / Racing / City 套件低多边形模型；码件吊装/隧道拱/针叶树场景
- AI（`ai.js`）：样条巡航 + 提前量警车追踪
- 比赛裁判（`race.js`）：状态机 countdown→running→finished；HUD P 名次/圈/时间
- M5：WebAudio 全合成音效（引擎双锯齿随转速、漂移/氮气噪声、碰撞、哔、stinger）；
  后视镜 = 车尾 RT 二次渲染（隔帧）+ overlay quad；小地图离屏底图 + 动态点
- CSP：`default-src 'self' blob: data:`，库共用 `site/assets/`
