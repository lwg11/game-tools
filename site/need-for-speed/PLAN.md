# 《极品飞车》风格新游 · 调研与架构方案（落地前评审稿）

> 状态：**方案评审中（8.7：先不写代码，调研+方案确认后再开工）**
> 目标一句话：海洋城市 + 山体海岸，白天黄昏不同时段可赏景、可自由开；多种比赛（竞速/漂移/对撞/武器/警匪），车辆可改装、可组装武器、可升级，视觉不像素、特效拉满。

## 0. 需求对应（来自用户 8.1–8.9）

| 用户要求 | 本方案落点 |
|---|---|
| 自由度高、可比赛可遨游 | 同一张大赛道地图，漫游模式默认开；比赛入口分布在全城（码头/海岸/隧道） |
| 参考 QQ 飞车 + 极品飞车 | QQ：氮气集气、漂移、Q 版爽感；NFS：警匪追逐、改装、海岸公路（见 §1） |
| 海边赛道、警车追逐、风景 | 海滨大道 + 半山发夹弯 + 日落/黄昏动态光照（§3） |
| 氮气加速、漂移分 | 漂移集气→氮气释放；漂移积分赛制（§4.5/§4.6） |
| 视觉震撼、碰撞火花、车损 | 火花粒子、尾流、轮胎痕、形变车损、运动模糊/速度线/镜头震动（§5.4/§5.5） |
| 多场景、可配置/组装、可装武器、升级 | 三类场景（海滨/山地/工业区）；车辆分模块升级（引擎/涡轮/轮胎/装甲/武器）；武器可挂载（§4.4/§4.7） |

## 1. 竞品调研（要点摘要）

- **极品飞车（NFS, EA Ghost）**：强项 = 警匪追逐（Heat 系列通缉等级/警车战术）、**深度车辆改装与性能升级**、巡演式开放世界、丽娃海滨/山地公路、漂移与氮气两大爽点、照片级车损与特效。
- **QQ 飞车 / 跑跑卡丁车**：强项 = 低门槛+高爽感（集气式氮气、漂移集气）、车辆**外观改装+部件升级**、赛道主题化（海滨/城市/雪山）、武器/道具赛。
- **竞品短板（我们的差异点）**：NFS 主机量级、不敢做"武器对战"；手游 UI/广告重。Web 端机会：无需下载、单机即点即玩 + 搞怪比赛类型脑洞（对撞、武器、护送）。

## 2. 技术选型（8.8）

| 层 | 选型 | 理由 |
|---|---|---|
| 渲染 | **Three.js r160**（本地 vendor，已在 vice-city 验证） | Web 即开即玩；复用场景/物理/粒子经验 |
| 模型 | **glTF 2.0 管线**（新增 `vendor/GLTFLoader`），Quaternius / Kenney CC0 资产（§6） | 真实感 + 离线可跑（资产入库，运行时零外网依赖） |
| 场景 | **程序化路网 + 手工模块化拼接**（混合） | 赛道手感可控；建筑/道具可批量摆放；保留程序化碰撞 |
| 物理 | 自研轻量载具物理（arcade：抓地/漂移/滑移角），复用 vice-city vehicle.js 思路升级 | 街机手感 > 真实模拟；避免引入 cannon/rapier 体积 |
| 音频 | WebAudio 合成（sfx.js 思路）+ 可选 CC0 引擎声采样 | 零授权风险 |
| 平台 | 响应式：桌面键鼠 + 移动端触屏（从 vice-city 搬 InputManager） | 双端交付 |

**是否沿用当前工程方式**：沿用 `game-tools/site/<game>/` 的独立静态站结构、headless 自检 + 本地服务 + deploy.py 部署；**新增** glTF 加载与资产目录（不再纯程序化方块）。

## 3. 世界与场景

- 一张 4km² 地图：**海滨大道（Ocean Drive 风）→ 商业中心 → 码头 → 北方山体（发夹九连弯）→ 隧道 → 工业区**。
- 关键奖励点：**海景日落**（动态天空盒+体积光感）、**海滨木栈道**、**霓虹商区**、**山道树影隧道**。
- 时间系统：默认黄昏（暖色+长影，最上镜）；首局教学后解锁白天/夜晚。
- 加载：整张图一次加载（动态植被/车流用池化），不做无缝大地图流式（控制范围）。

## 4. 玩法规格

### 4.1 操作
- 驾驶：WASD/方向键 + 手刹漂移（Space）+ 氮气（Shift/N）+ 镜头（鼠标）。
- 触屏：双摇杆 + 漂移/氮气大按钮。

### 4.2 漫游模式（自由）
- 无目标全城开，地图标记比赛入口/商店/改装铺/隐藏收集（车牌 50 个）。

### 4.3 比赛入口与流程
- 到光环处按 E 进入 → 选模式/难度 → 倒计时 → 比赛 → 奖励（金币/部件/涂装）。

### 4.4 车辆系统（可配置/可组装/可升级）
- 4 个基础车型（** Mini 灵巧 / Street 均衡 / Muscle 大马力 / Exotic 超跑 **），开局 1 台，其余金币解锁。
- **部件升级**（每部件 5 级，金币或比赛奖励）：引擎（极速）、涡轮（氮气效率/时长）、轮胎（过弯抓地/漂移可控性）、装甲（耐久/对撞）、氮气罐（容量）。
- **外观**：车漆（含渐变）、轮毂、尾翼、拉花（涂装模块）。
- 性能面板可视化（速度/加速/操控/耐久/氮气 5 维雷达）。

### 4.5 氮气与漂移
- **集气**：直线高速（>85% 极速）充能快；漂移充能快 2 倍 → 鼓励漂移流（QQ 手感）。
- **释放**：爆发加速 + 屏体特效（§5.5）。**侧向氮气**（高级操作）：点按小喷修正车头。
- **漂移积分**：按滑移角×速度×持续时间计分，断漂清零。

### 4.6 比赛类型（脑洞，先列 7 种，落地先做前 4 种）
1. **海滨环线竞速**（4 圈，4 车，直线+弯，纯速度）。
2. **漂移积分赛**（90 秒，山道多弯，分数制）。
3. **淘汰圈**（每 20 秒末位淘汰至最后一人）。
4. **警匪追逐**（警车截停：耐久归零前到达终点；警用路障/撞击）。
5. **对撞赛**（封闭场地，撞飞对手得分；低耐久惩罚）。
6. **武器对决**（道具拾取 + 车载武器：钉刺/EMP/机枪/油桶，击毁或积分）。
7. **城市寻宝计时**（检查点限时，路书引导）。

### 4.7 武器/装备（可组装）
- 挂载槽 2（前/后）+ 1 通用；武器实例：${钉刺带}、EMP（短时瘫痪）、机枪（直线骚扰）、油桶（后抛）、护盾。
- 武器由比赛奖励解锁；只在对应比赛类型中启用。

### 4.8 对手强度（AI）
- 三档难度：**业余 / 职业 / 车神**（初始速度补偿、走线精度、攻击性、橡皮筋强度）。
- AI 走线 = 赛道样条插值 + 车距保持 + 简单避让/卡位；警匪 AI 额外有拦截/夹击脚本。

### 4.9 经济/进度
- 金币：比赛名次 + 漂移分 + 隐藏收集；消费：车辆/部件/涂装。
- 存档：localStorage + 可选云同步（沿用 progress.js 通道）；防作弊：仅记录完成度，数值本地运算。

## 5. 视觉与特效（8.4）

### 5.1 基础
- 色调映射 ACESFilmic + 黄昏主光 + 霓虹补光；阴影（PCF 软阴影）。
- 车辆：glTF 低模+法线贴图（Quaternius/CC0），多车漆实例共享几何。

### 5.2 环境
- 海：ShaderMaterial 波浪 + 边缘泡沫 + 反射感（假反射：天空色渐变）。
- 山：山体网格 + 树/岩实例（InstancedMesh）。
- 天空：渐变穹顶 + 太阳盘 + 云层（柔和噪声纹理），昼夜平滑过渡。

### 5.3 车辆细节
- 车轮独立旋转/转向、转向时机头灯、尾灯刹车变亮、排气管火焰（氮气时）、扰流板随速度下压（视觉）。
- 车损：耐久 <50% 冒烟，<25% 冒火+车身部件移位/掉件（复用 vice-city a2c01a2 思路），损毁→原地修理/重生。

### 5.4 碰撞反馈
- 火花粒子池（复用 `_vc` spawnSparks）+ 金属撞击音 + 镜头震动 + 短暂运动模糊（后处理或 UV 抖动贴片），碰撞双方掉耐久。

### 5.5 速度感
- 氮气：屏幕边缘速度线（shader/贴片）、FOV 拉伸 + 尾焰粒子 + 空气热浪贴片感。
- 漂移：轮胎烟雾粒子 + 轮胎痕（decal 网格池）+ 漂移提示 UI（实时分数）。
- 高速近景：方向性动态模糊（简化后处理）。

## 6. 资产调研与清单（#5、#8.8：图片/模型）

> 调研方式：直连外网抓取官网/接口；三种许可模式：CC0（可商用免署名）、Royalty-free。最终资产**入库到 `site/need-for-speed/assets/`**（运行时零外网依赖）。

| 来源 | 地址 | 许可 | 格式 | 可用内容 | 建议用途 |
|---|---|---|---|---|---|
| **Quaternius** | quaternius.com/packs/cars.html | CC0 | FBX/OBJ/Blend | 低模汽车包（8 车、带动画） | 需先转 glTF（Blender 脚本）→ 首期主角车 |
| **Quaternius** | quaternius.com/packs/downtowncitymegakit.html | CC0 | FBX/Blend/**glTF** | 300+ 模块化城市件（含假窗内景 shader、倒角） | 海滨商区/城市建筑模块 |
| **Quaternius** | quaternius.com/packs/animatedmen.html、buildings.html | CC0 | FBX/OBJ/Blend | 动画小人 / 9 建筑 | 行人与静态楼（转换） |
| **Kenney** | kenney.nl/assets/city-kit-commercial 等 | CC0 | glTF 导出 | 商业/郊区/工业 50+ 楼块、Car Kit | 备用/原型期快速搭场景 |
| **Poly Haven** | polyhaven.com（api.polyhaven.com/assets?type=models） | CC0 | glTF | 522 模型（无车辆类；道具/工业/家具全） | 码头/车库/赛道道具、集装箱、轮胎堆 |
| **three.js** | threejs.org + 本地 `lib/` | MIT | ESM | GLTFLoader/后期处理 | 已 vendor three，新增 loader |
| **HDRI/贴图** | polyhaven.com（HDRIs/textures） | CC0 | hdr/jpg | 天空盒、柏油/水泥/金属 PBR 贴图 | 提升“华丽真实”关键 |
| Mixamo | mixamo.com | 需登录/Adobe 授权 | FBX | 角色动画 | 暂不用（授权复杂） |

**决策**：呈现风格 = **低多边形 + PBR 贴图的偏写实**（不是体素像素，也不是照片级），美术风格与霓虹海滨一致。首选 Quaternius（glTF、波士顿/纽约风格模块化、自带窗景），Poly Haven 补道具与贴图。

## 7. 架构设计

```
site/need-for-speed/
  index.html        页面骨架 + HUD + 菜单（沿用 vice-city 风格）
  style.css         UI
  lib/             three.module.min.js + GLTFLoader.js（vendor）
  assets/          glTF 车辆/城市模块/贴图/音频（CC0 入库）
  js/
    main.js           启动/主循环/状态机（菜单→漫游→比赛→结算）
    config.js         全部数值（车/部件/武器/奖励）
    input.js          键鼠+触屏 InputManager（移植 vice-city）
    world.js          赛道/城市/海/山生成 + 碰撞 + 检查点
    spline.js         赛道样条（中心线/路缘/路点）
    car.js            车辆物理（漂移/滑移/氮气/耐久）+ 视觉（glTF/轮毂/尾焰）
    traffic_ai.js     车流/景物车
    cop.js            警车 AI（追逐/路障/夹击）
    race.js           比赛流程（检查点/排名/计时/淘汰/警追结算）
    ai.js             对手 AI（难度档/走线/攻击）
    weapon.js         道具/武器系统
    nitro.js          集气/释放（并入 car？保留独立便于平衡）
    fx.js             粒子：火花/烟/胎痕/尾焰/速度线
    hud.js            速度/名次/小地图/氮气条/漂移分（移植移 HUD）
    store.js          存档（进度/金币/涂装/部件）
    sfx.js            WebAudio 合成（引擎声按转速变调、警笛、碰撞）
```

**核心接口**（示例约束）：
- `world.checkpointAt(i)` → {center, dir}；`race.update` 每帧吃 `car.progress`（样条弧长投影）；
- 物理固定步长 1/60（沿用）；渲染插值；AI 走线 = 样条 + lookahead。
- 全部模块要求 **headless 安全**，延续 `tools/_*_headless_test.mjs` 自检传统。

## 8. 里程碑（方案确认后执行）

1. **M1 骨架（3-4 天）**：倾斜/转向样条赛道 + 车辆物理 + chase cam + headless 自检（能"开起来"）。
2. **M2 世界（5-7 天）**：海滨大道+商区+山道+海/山/天空；glTF 城市模块与车辆接进来。
3. **M3 竞速闭环（4-5 天）**：检查点/排名/计时/4 种比赛模式；AI 三档；小地图/HUD。
4. **M4 成长（4-5 天）**：金币/部件升级/涂装/车辆解锁；7 种比赛类型（先4）。
5. **M5 特效与警匪（5-6 天）**：氮气/漂移/碰撞/车损/特效拉满；警车追逐 + 路障。
6. **M6 打磨自测（3-4 天）**：完整跑多局、修 bug、移动端、部署。

## 9. 风险

- **glTF 资产管线**：Quaternius 部分包只有 FBX/OBJ → 需要一次性 Blender 批量转换（先做, 风险中）。
- **物理手感**：漂移/氮气平衡需大量试错 → M1 先做手感原型（灰色场景即可验证）。
- **性能**：特效密度 → 全部走对象池 + Instanced；目标 PC 60fps / 移动端 30fps。
- **内容量**：7 种比赛先做 4 种，剩余作为更新。
- **授权**：只入库 CC0/自有资产；音频若用采样需确认授权，优先合成。

## 10. 自测方案（8.9 交付前）

- headless：物理单测（加速/刹车/漂移/碰撞掉血/氮气消耗）、样条弧长与检查点判定、比赛流程状态机、AI 走线散布、存档读写、经济数值（升级贵曲线收敛）。
- 浏览器（Playwright+本地 chrome）：跑通 4 种比赛模式各多局（含警追、对撞、武器）、帧率采样、移动端布局。
- 人工体验清单：手感、画面、特效、引导、结算、升级是否"值得刷"。
